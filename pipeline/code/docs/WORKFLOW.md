# 整体流程（权威范围文档）

> 本文件是实验室整体分析流程的权威描述，原文照录。
> 本工程当前实现 **第 1–4 步**；第 5–8 步明确不在范围内。
> Ks 分析是第 4 步内的可选分支（`WGDI_KS=true` 启用，默认关闭）。

## 流程原文

1.数据收集并整理
根据所给网址进行数据收集（优先选择测序最完整，论文发表时间最新的链接），可以选择下载此物种的原始文献，并且需要确定此物种的染色体数目；网址通常包含多种类型，主要下载的是 gff 3、pep（蛋白类）、cds、mrna、gbff文件，如果此物种并没有这些，或者不适合进行完整分析流程，请在表格中标注出来。

2.数据预处理
需要将上述收集的数据整理成wgdi需要的格式，主要包括，pep、cds、gff、lens 文件，其中主要基于 pep进行blast 比对，cds 可以与 pep一一对应，gff 是基因组注释文件，lens 是根据 gff生成的，仅wgdi 需要。

3.运行blast（使用diamond 软件）
blast 主要用于两个物种进行序列比对，可分为物种内部比对、A 物种与 B 物种比对，通过观察这两类比对的点图，可以大致确定物种在一个类群中的加倍事件过程，具体分析过程比较复杂，需要具体科目、具体加倍事件具体分析。比如有的物种会加倍两倍，有的会加倍三倍，甚至还有五倍体。

4.运行wgdi

5.构建系统发育树
宜粗不宜细，下一步再自己检查

6.查找所分析物种的系统发育树，与自身生成的系统发育树进行比对；根据点图判断系统发育过程中的加倍关系，并与学术界最前沿的相关论文核对加倍事件发生的节点。
主要需要人工进行复杂分析，调查分析确认，最好多方比对，因为大多数情况一个论文一个样，不过有共通之处，求同存疑，优先参考最新的、影响因子较高的论文，但是并不代表此论文完全正确。

7.使用多重共线性分析程序，构建多重比对列表
此步比较复杂，后续再描述

8.使用多重比对列表构建圈图。
画图，较为简单

## 本工程对第 1–4 步的实现映射

| 流程步骤 | 实现入口 | 产物/记录 |
| --- | --- | --- |
| 1 数据收集并整理 | 用户按网址自行下载（优先测序最完整、发表最新）；`init-project` 注册本地文件，`prepare`/`batch` 批量路由；不可用物种在清单与失败记录中标注原因，不强制补全 | `resources/download_inventory.tsv`、失败原因记录 |
| 1 确定染色体数目 | `run` 输出染色体清单；`chromosomes` 查看；`adjudicate` 人工确认签字（绑定 QC 版本+SHA-256） | `<Abbr>.chromosome_map.tsv`、裁决记录 |
| 2 数据预处理 | `run`（代表转录本：CDS 最长优先 + 稳定 ID 字典序；严格染色体筛选为 CLI 默认，`--sequence-mode adaptive` 为碎片化组装逃生门）→ `validate` → `check-names` | `<Abbr>.pep/.cds/.new.gff/.lens` 四件套；`gene_map.tsv`、`removed_list.tsv`、`qc_record.md`、`qc.json` |
| 3 DIAMOND 比对 | `run_homology.sh`（或 `1run_diamond.sh`/`1run_blast.sh`），物种内 + 物种间两两比对，默认 e-value 1e-5 | `wgdi_input/blast/<A>_pep/<A>_<B>.blast`、点图输入 |
| 4 WGDI 共线性 | `2gen_wgdi_conf.sh`（读 `species_map.tsv` 生成扁平比较目录与相对路径配置，零复制）→ `3run_wgdi.sh`；默认只跑 dotplot + collinearity | `<prefix>.png`、`<prefix>.icl` |
| 4 可选 Ks 分支 | `WGDI_KS=true`（Windows 总控 `-WithKs`）追加 ks/blockinfo/correspondence/blockks/kspeaks/peaksfit 六阶段 | `.ks`、`.bi.csv`、`.bi.c.csv`、`.bk.png`、`.kp.png`、`.pf.png` |

## 明确不覆盖（第 5–8 步）

- 系统发育树构建（第 5 步）
- 已发表树比对与加倍节点文献核对（第 6 步，人工分析）
- 多重共线性分析与多重比对列表（第 7 步）
- 共线性圈图绘制（第 8 步）

分析开始前必须向用户声明上述边界。第 4 步的共线性块与点图是第 5–8 步的输入，
但本工程不执行也不声称完成这些后续步骤。
